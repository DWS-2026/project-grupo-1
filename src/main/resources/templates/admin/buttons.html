Botones de Marca

Los botones de Google y Facebook están disponibles con el color de marca de cada empresa. Se usan en las páginas de inicio de sesión y registro de usuarios.

Puedes crear más botones personalizados agregando una nueva variable de color en el archivo _variables.scss y luego usando el mixin de variante de Bootstrap para crear un nuevo estilo, como se muestra en el archivo _buttons.scss.

.btn-google .btn-facebook
